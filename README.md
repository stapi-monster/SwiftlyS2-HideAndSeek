# 🎮 HideAndSeek (Прятки / Маньяк) для SwiftlyS2 (CS2)

Мощный и полностью настраиваемый плагин игрового режима **HideAndSeek (Прятки / Маньяк)** для серверов Counter-Strike 2 на платформе **SwiftlyS2**.

В этом режиме один или несколько игроков становятся **Маньяками (Террористы / Team T)**, а остальные — **Выжившими (Контр-Террористы / Team CT)**.

---

## 🌟 Ключевые возможности

- 📥 **Система очереди на маньяка**: Игроки могут вставать в очередь на роль маньяка с помощью чат-команд (`!q`, `!row`, `!й`, `!кщц`).
- ⚖️ **Динамический балансировщик (`maniacbalance`)**: Автоматический выбор количества маньяков в зависимости от текущего онлайна на сервере.
- 🎲 **Рандомный выбор маньяков**: Если очередь пуста или игроков в очереди не хватает, плагин автоматически выберет случайных игроков (включая ботов).
- 🛡️ **Бессмертие маньяков (Godmode)**: Маньяки **всегда бессмертны** в течение всего раунда, независимо от количества HP.
- 🔪 **Кастомизация маньяка**: Установка собственного количества HP (`maniachp`) и выдача вооружения/гранат при спавне (`maniacweapons`).
- ⏱️ **Таймер выхода и поддержка карт Мастерской (Workshop)**: Гибкая настройка времени задержки выхода маньяка для любой карты в `maps.jsonc`.
- 📺 **Интерактивное HUD Menu**: Отображение времени до выхода маньяка на экране в реальном времени.
- 🚫 **Защита от смены команд**: Обычные игроки не могут зайти за команду маньяков через меню игры или консоль (`jointeam`). Маньякам запрещено менять команду во время раунда.
- 🔁 **Авто-респавн выживших**: Выжившие возрождаются, если погибли ДО того, как маньяк вышел из затона.
- 🌐 **Мультиязычность**: Полная поддержка переводов (Русский `ru.jsonc`, Английский `en.jsonc`).

## 📦 Установка

1. Скопируйте скомпилированную папку плагина `HideAndSeek` в директорию вашего сервера:
   ```
   /game/csgo/addons/swiftlys2/plugins/HideAndSeek
   ```
2. Перезапустите сервер или загрузите плагин на лету командой:
   ```bash
   sw plugin load HideAndSeek
   ```

## 🛠️ Сборка и компиляция (Windows и Linux)

Так как плагин написан на C# (.NET 10.0), скомпилированная сборка `.dll` является **кроссплатформенной** благодаря управляемой среде хостинга SwiftlyS2 (`hostfxr`). Один и тот же скомпилированный файл `.dll` работает **как на Windows, так и на Linux серверах CS2**.

### 1. Стандартная универсальная сборка (для всех ОС):
Откройте терминал в директории плагина и выполните:
```bash
dotnet publish -c Release -o ./bin/Release/publish
```

### 2. Сборка под конкретные ОС (Target RIDs):
При необходимости таргетинга на конкретные платформы:

- **Для Windows (win-x64)**:
  ```bash
  dotnet publish -c Release -r win-x64 --no-self-contained -o ./bin/Release/windows
  ```

- **Для Linux (linux-x64)**:
  ```bash
  dotnet publish -c Release -r linux-x64 --no-self-contained -o ./bin/Release/linux
  ```

## 📜 Команды игрока

| Команда | Описание |
| :--- | :--- |
| `!q`, `!row`, `!й`, `!кщц` | Встать в очередь или выйти из очереди на маньяка |
| `!queue`, `!qlist`, `!очередь` | Посмотреть текущий список игроков в очереди |
| `!hnsound`, `!hnssound` | Включить или выключить проигрывание звука выхода маньяка |

## ⚙️ Конфигурация плагина (`config.jsonc`)

Файл конфигурации автоматически создается в папке плагина при первом запуске из шаблона `config.template.jsonc`.

```jsonc
{
  // Команды для захода/выхода из очереди на маньяка (разделитель - запятая)
  "commands": "q, row, й, кщц",

  // Команды для просмотра текущего списка игроков в очереди на маньяка
  "showqueue": "queue, qlist, очередь",

  // Звук при отказе перехода за команду маньяка (!jointeam / меню игры)
  "soundPathNoAccessJoinTeam": "sounds/ui/weapon_cant_buy",

  // Звук при выходе маньяка из затона
  "soundpathmaniac": "sounds/ui/killcard_1_e",

  // Состояние звука выхода маньяка по умолчанию для новых игроков
  "stateAutoEnableSound": true,

  // Разрешено ли действующему маньяку вступать в очередь на следующий раунд
  "stateManiacJoinInQueue": false,

  // Выбирать ли маньяком игрока из прошлого раунда, если нет очереди
  "addManiacInRandom": false,

  // HP маньяка при спавне (маньяк при этом ВСЕГДА бессмертен)
  "maniachp": 666,

  // Дополнительное оружие и гранаты для маньяка
  "maniacweapons": [
    "weapon_taser",
    "weapon_hegrenade",
    "weapon_flashbang"
  ],

  // Авто-респавн выжившего (CT), если он умер ДО выхода маньяка
  "autoRespawnSurvivor": true,

  // Длительность отображения плашки "Маньяк вышел!" после таймера (в секундах)
  "durationdisplayaftertimer": 5.0,

  // Балансировщик количества маньяков от онлайна ("онлайн": количество_маньяков)
  "maniacbalance": {
    "1": 1,
    "8": 2,
    "16": 3
  }
}
```

## 🗺️ Конфигурация карт (`maps.jsonc`)

Файл `maps.jsonc` отвечает за время задержки выхода маньяка (в секундах) для разных карт. Поддерживаются как стандартные карты, так и карты из **Steam Workshop**.

```jsonc
{
  "maps": {
    // Чистое название карты
    "hns_baggage": 15,
    "de_dust2": 30,
    "cs_office": 20,

    // Или полный путь карты Мастерской
    "workshop/3070194538/hns_baggage": 15
  },

  // Задержка по умолчанию, если карта отсутствует в списке выше
  "defaultReleaseTime": 30
}
```
